## Суть
На текущий момент, при загрузке выписок банка через выгрузку-->загрузку XML банка в 1С:УТ, в автоматически устанавливаемых реквизитах выписки банка 1С (по реквизитам XML выписки) не устанавливаются ставки НДС (залочено на значение = 0). 

Необходимо проверить модуль загрузки XML выписок и посмотреть правила значений реквизитов. НДС должен заполняться корректно, насколько знаю в XML файле есть отдельные уникальные параметры, отвечающие за состояние, значение и вида НДС, нужно сопоставить их с реквизитами в 1С
