## Суть
Сделать обработку, которая собирает всех контрагентов и разделяет их на неиспользуемые (можно удалять) и используемые (удалять запрещено).

## Контекст
Две табличные части:
1. Контрагенты, карточка которых никуда не направлена — не используется в других объектах 1С.
2. Контрагенты, которые где-то используются — удаление запрещено.

## Что сделать
- [ ] Алгоритм поиска дублей (ИНН/КПП, наименование)
- [ ] Поиск ссылок на контрагента (ПоискСсылок / запросы по метаданным)
- [ ] Форма с двумя табличными частями
- [ ] Пометка на удаление только для неиспользуемых
- [ ] Тест на копии базы

## Критерии готовности
- Обработка корректно делит контрагентов на две группы и не даёт удалить используемых

## Материалы
